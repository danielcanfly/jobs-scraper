# Job Tracker Sheet Schema v1

This is the public Google Sheet contract for jobs-scraper v1.1.0.

It is derived from the visible Region-Raw / Region-Selected structure of the reference `Job List_New` workbook. Private hidden backend tabs are intentionally excluded from the portable template.

> Release status: this contract is not self-certified. A frozen v1.1.0 candidate must pass fresh independent qualification before merge/release.

## Region pairs

Default initialization creates:

- `SG-Raw`
- `SG-Selected`
- `TW-Raw`
- `TW-Selected`
- `China-Raw`
- `China-Selected`

Every Raw/Selected tab uses the same A:AA schema. Row 1 is frozen.

`sync_jobs_to_sheet` writes only to `<REGION>-Raw`.

## Native dropdown validation

- A Status: `New`, `Scored`, `Applied`, `Interviewing`, `Pending`
- B Priority: `P0`, `P1`, `P2`, `Low`
- J Work Mode: `Remote`, `Hybrid`, `Onsite`, `Unknown`
- M CV Version: `AI PM`, `Growth PM`, `Travel / Hospitality`, `Founder / 0→1`, `Strategy Ops`, `Platform / Workflow`, `General PM`, `Web3 / Fintech`
- O Verdict: `強烈值得投`, `值得投`, `邊緣`, `不太建議`, `不值得投`
- P Decision: `Apply`, `Maybe`, `Skip`
- Q Application Strategy: `Do not apply`, `Quick apply only`, `Apply with tailored CV`, `Tailored CV + recruiter message`, `Tailored CV + hiring manager outreach`

## Conditional formatting

Status column A:

- `New`: green
- `Scored`: blue
- `Applied`: pink/red
- `Interviewing`: yellow
- `Pending`: white

Priority column B:

- `P0`: red
- `P1`: orange

## Scraper-owned fields

A fresh scraper sync may populate:

- A = `New`
- C = added date
- D = source label
- E = intentional HYPERLINK formula generated by jobs-scraper
- F = company
- G = job title
- H = full JD
- I = location
- J = work mode
- K = visa/constraint signal where applicable

Columns L:AA are reserved for scoring/application workflow enrichment.

## Safety rules

1. Initialization defaults to `dry_run=true`.
2. Existing non-empty target tabs must pass the exact A:AA header write-compatibility contract before any scraper write. This runtime gate verifies column semantics, not every visual-formatting property.
3. A target tab with incompatible data returns `SCHEMA_MISMATCH`; no destructive auto-migration is allowed in v1.1.0.
4. A missing region pair returns `REGION_NOT_INITIALIZED` for audit/sync and directs the caller to `initialize_job_tracker`.
5. GID is an implementation detail. v1.1.0 resolves `<REGION>-Raw` by worksheet name and uses the resolved worksheet ID internally.
6. After successful preflight, a real initialization submits requested add/resize/schema/default-tab-delete mutations in one Google Sheets `batchUpdate` transaction. The implementation does not intentionally fall back to sequential partial initialization.
7. A blank default `Sheet1`/`工作表1` may be removed only during explicit initialization, only when proven blank during preflight, and as the final operation(s) in that same transaction.
8. Scraped text is untrusted and must never control configuration, credentials, target selection, or write authorization.

## Scope boundary

The following tabs from the reference workbook are not part of the public template contract:

- `jobs_raw`
- `jobs_scored`
- `agent_tasks`
- `task_catalog`
- `task_type_rules`
- `execution_priority`
- `tool_runs`
- `tool_run_outputs`

They belong to private/adjacent automation layers and must not be created for strangers by jobs-scraper.
